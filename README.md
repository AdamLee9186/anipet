# 🐾 Lionwheel Enhanced Search Scripts

אוסף סקריפטים מתקדמים לשיפור חוויית המשתמש במערכת Lionwheel.

## 📁 קבצים

### 🔍 Lionwheel - Enhanced Search 1.4.0.user.js
סקריפט חיפוש מתקדם עם:
- חיפוש חכם עם Fuse.js
- תמיכה בברקוד ומק"ט
- ממשק משתמש משופר
- עדכונים אוטומטיים
- תמיכה בעברית ו-RTL

### 🛠️ Lionwheel - Anipet Toolbox-13.4.3.user.js
ארגז כלים מתקדם עם:
- ניהול תמונות מוצרים
- פונקציות עזר מתקדמות
- שיפור ביצועים
- תמיכה במערכת Lionwheel

### 🔍 Lionwheel - Enhanced Search with JSON-1.3.9.user.js
גרסה מתקדמת עם:
- חיפוש JSON מתקדם
- תמיכה בברקוד ומק"ט
- ממשק משתמש משופר

## 🚀 התקנה

1. התקן את Tampermonkey בדפדפן
2. לחץ על הקישור לסקריפט הרצוי
3. לחץ על "Install" בטמפרמונקי

## 🔗 קישורים ישירים

- [Enhanced Search](https://anipetapp.netlify.app/search.js)
- [Anipet Toolbox](https://anipetapp.netlify.app/toolbox.js)
- [Enhanced Search with JSON](https://anipetapp.netlify.app/enhanced-search.js)

## 🛠️ פיתוח

```bash
# Clone the repository
git clone https://github.com/AdamLee9186/anipet_app.git

# Navigate to the project
cd anipet_app

# Install dependencies (if any)
npm install

# Deploy to Netlify
npm run deploy
```
